Factory Speech Cleaner - portable Windows release

Strength 50 now uses the approved smooth-context engine: 12-second processing
windows with smooth overlap. Previous Reference remains available in comparisons.
Keep Detail recovery off to hear the approved sound.

Copy the WHOLE FactorySpeechCleaner folder to a writable location on the destination
Windows PC. Keep the EXE and _internal folder together. Python is bundled.

1. Open FactorySpeechCleaner.exe.
2. Select audio/video files or a folder in Control Room.
3. Choose a separate output folder and start with strength 50.
4. Select a queue row and click Prepare preview. Press Play in Selected file,
   then adjust Cleanup strength. Pause briefly for each update.
   The first AI preparation takes longer; subsequent slider changes reuse it.
5. Click Clean files when ready to export the queue.
6. Use Listen A or Listen B to compare versions. Find results with Open cleaned
   files. The How to use tab explains the workflow and settings.

Advanced options and technical logs are collapsed by default. Expand them only
when needed. No files are automatically selected on startup.

Detail recovery (experimental, slower) uses two local models to recover complementary
speech detail. Enable it to try the independent-engine improvement. Leave it off for
the accepted Reference baseline. A/B generation keeps Reference 50 available alongside
the selected detail-engine version. Compare before using it on a full library.

Audio sources export 48 kHz WAV. Video exports retain the original video stream.
Strength 0 bypasses processing. Folder selection scans only that folder, not subfolders.
Existing exports are skipped unless Replace existing CLEAN files is enabled.
Failures and fallback processing appear in the queue and session logs.
Each new export includes a JSON report. Processing is local; media is not uploaded.

This release uses CPU inference. Higher strength is not necessarily clearer speech.
